# OmniReader
RFID MIFARE Classic laboratory toolkit in Python
1. Detección de lector: localizar y seleccionar dispositivos OMNIKEY compatibles PC/SC.

2. Diagnóstico: comprobar comunicación PC/SC y estado del servicio pcscd.

3. Identificación: consultar UID y ATR de la tarjeta.

4. Monitor RFID: detectar cuándo se aproxima o retira una tarjeta en tiempo real.

5. Lectura: leer el bloque 4 de MIFARE Classic utilizando una clave conocida.

6. Escritura: modificar el bloque 4 y verificar posteriormente los datos escritos.

7. Comparación: comparar el contenido leído con una secuencia HEX esperada.

8. Análisis: visualizar datos en hexadecimal, ASCII, decimal y binario.

9. Conversor: convertir datos entre HEX y texto.

10. Informes: exportar resultados en formato JSON.

11. Mapa de memoria: visualizar la estructura de sectores y bloques de MIFARE Classic 1K.

12. Autodiagnóstico: ejecutar pruebas locales de validación.

13. Ayuda: instrucciones de instalación y funcionamiento.
